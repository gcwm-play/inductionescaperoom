Data Run

One of the data points is stored in a far-away storeroom.

Send your fittest (or fastest-fingered) team member to fetch it back!

How it works:

  1. Pick a mode below — Run or Tap — based on how much space you've got to move in.
  2. Tap Start, then keep going until the on-screen counter reaches the goal.
  3. Reaching the goal reveals the unlock code — bring it back to your team's main device.
